# Caio Oliveira Pacifico

Desenvolvedor de software e estudante de Sistemas de Informação, com interesse em desenvolvimento de aplicações, sistemas desktop, áudio, infraestrutura e automação.

Atualmente trabalho na **Playlist Software Solutions**, atuando com suporte técnico, análise de problemas, sistemas, redes e infraestrutura. Paralelamente, desenvolvo projetos próprios para aprofundar meus conhecimentos e transformar ideias em software.

Meu foco atual está principalmente em **C++, C#, TypeScript, Python e Go**, explorando desde aplicações desktop e APIs até aplicações web, bancos de dados e infraestrutura.

## Projetos

### Audioslave

Ferramenta desktop em C++ voltada para gerenciamento de dispositivos de áudio do Windows, explorando APIs do sistema e controle de comportamento dos dispositivos.

`C++` `JUCE` `Windows` `Audio`

### Audio Watchdog

Serviço para Windows que monitora dispositivos de áudio e desativa automaticamente o modo exclusivo, ajudando a manter aplicações de áudio funcionando de forma consistente.

`C++` `Windows` `Audio`

`TypeScript` `Flutter` `Mobile`
